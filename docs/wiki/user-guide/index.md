# User Guide

Follow the guides in order for a new native installation. Existing Semaphore
installations can keep their provider; see [configuration](configuration.md).

1. [Install the integration and backend](installation.md).
2. [Configure the connection and authentication](configuration.md).
3. [Add hosts and verify access](hosts.md).
4. [Check status, install updates and inspect jobs](updates-and-jobs.md).
5. [Create optional custom tasks](custom-tasks.md).

For ongoing operation, use [backup and removal](backup-and-removal.md),
[troubleshooting](troubleshooting.md) and [frequently asked questions](faq.md).
The [product behavior guide](../product/behavior.md) explains what a successful
operation means and where explicit confirmation is required.
