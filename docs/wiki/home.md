# Homelab Commander Wiki

Homelab Commander brings Linux host status and deliberate maintenance actions into
Home Assistant. The native backend manages hosts, SSH identity and jobs; the
integration provides devices, entities and a direct backend UI entry.

| Area | Audience | Contents |
| --- | --- | --- |
| [User Guide](user-guide/index.md) | Installers and operators | Installation, configuration, hosts, updates, jobs, tasks, recovery and troubleshooting |
| [Product](product/index.md) | Product owners and reviewers | Purpose, supported behavior, acceptance and roadmap |
| [Technical](technical/index.md) | Developers and maintainers | Architecture, integration, API, execution, persistence, security and testing |
| [Maintenance](maintenance/index.md) | Contributors and release maintainers | Documentation ownership, releases and contribution workflow |

New here? Start with [installation](user-guide/installation.md), then
[host onboarding](user-guide/hosts.md). To investigate a failure, use
[troubleshooting](user-guide/troubleshooting.md).

The current project version is a development release. Successful tests do not
mean a release has passed all security, packaging and installation gates.
Roadmap entries describe proposals, not currently available features.

These pages are maintained as versioned Markdown in `docs/wiki/` and published
as a reviewed snapshot. Report documentation corrections through an issue or MR;
see [documentation maintenance](maintenance/documentation.md). All areas contain
public-safe project information. No area is a private infrastructure notebook.
