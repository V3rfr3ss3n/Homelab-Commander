# Glossar

| Begriff | Bedeutung im Projekt |
| --- | --- |
| Automation Backend | Führt privilegierte Commands aus; in `0.1` Semaphore |
| Capability | Optional unterstützte Backendfunktion mit explizitem Vertrag |
| Config Entry | Persistierte, über Home Assistants UI verwaltete Integrationseinstellung |
| Coordinator | Zentraler Home-Assistant-Mechanismus für Statuspoll und Snapshot |
| Host-ID | Stabiler technischer Bezeichner aus dem Statuspayload und Commandziel |
| Status Provider | Liefert den aktuellen, read-only Hoststatus |
| Application Service | Orchestriert einen Use Case unabhängig von Transport und Entity |
| Adapter | Übersetzt zwischen externem API-Vertrag und internen Domainmodellen |
| ADR | Dauerhafte Dokumentation einer relevanten Architekturentscheidung |
| Quality Gate | Menge blockierender Prüfungen vor Merge oder Release |
| Public by default | Jeder Commit ist ohne spätere Bereinigung veröffentlichbar |
